PIYUSH & KRIPANSHA WEDDING WEBSITE — FINAL PROJECT

FILES
- index.html: page structure
- index.css: styling and responsive layout
- index.js: envelope, music, petals, scratch countdown, gallery lightbox
- image1.png: local couple photo used by the feature and gallery
- music.mp3: background music

HOW TO RUN
1. Extract this ZIP to a folder.
2. Open the folder in VS Code.
3. Make sure all five files stay together in the same folder.
4. Open index.html with Live Server.
5. If you replace the photo, keep the filename image1.png or update the src values in index.html.
6. Wedding date/time is set in index.js as 2026-12-04T19:00:00+05:30 (4 December 2026, 7:00 PM India time).
7. Event function times are written in index.html and can be edited there.

NOTE
The gallery currently uses image1.png in all four gallery slots because that is the only photo in the uploaded project. Replace the repeated src="image1.png" entries with the filenames of your other photos when you add them.
